# Lab 4: Advanced Functions and Patterns

## Overview

This lab covers:
- More complex function definitions
- Accumulator patterns
- Nested loops for pattern generation
- Mathematical series approximation (π)

## How to Set Up

1. Open `lab4.sln` in Visual Studio
2. Build the solution

## How to Run

1. Open the solution in Visual Studio
2. Press `F5` or click Debug > Start Debugging

## Questions (Programs)

### Question 1: Average Calculator
- Input: integers (enter -100 to end)
- Output: average of all entered integers

### Question 2: Smallest Integer
- Input: first number = count, followed by that many integers
- Output: smallest integer

### Question 3: Star Pattern
- Output: Complex pattern with multiple triangles of *

### Question 4: Pi Calculation
- Input: accuracy (number of terms)
- Output: Approximation of π using Leibniz series
  - π = 4 - 4/3 + 4/5 - 4/7 + ...

## Key Function

- **pi(term)**: Calculates π using Leibniz formula with alternating addition/subtraction

## Mathematical Details

Leibniz formula for π:
π = 4 × (1 - 1/3 + 1/5 - 1/7 + 1/9 - ...)
