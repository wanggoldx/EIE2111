# Lab 3: Functions and Control Structures

## Overview

This lab covers:
- Function definitions and calling
- Recursive mathematical functions
- Loop structures (while, for)
- Nested loops
- Basic encryption/decryption

## How to Set Up

1. Open `lab3.sln` in Visual Studio
2. Build the solution

## How to Run

1. Open the solution in Visual Studio
2. Press `F5` or click Debug > Start Debugging

## Questions (Programs)

### Question 1: Salary Calculator
- Input: sales amount in dollars
- Output: salary = $200 + 9% commission
- Enter -1 to end

### Question 2: Square Pattern
- Input: side length
- Output: Box pattern using * (border only)

### Question 3: Encryption/Decryption
- Input: 4-digit number
- Encrypt: each digit + 7, mod 10, then swap positions
- Decrypt: reverse the encryption process

### Question 4: Mathematical Functions
- **factorial(n)**: Calculates n! recursively
- **e(n)**: Calculates e ≈ Σ(1/n!) with given accuracy
- **ex(x, n)**: Calculates e^x ≈ Σ(x^n/n!) with given accuracy

## Key Functions

| Function | Description |
|----------|------------|
| factorial(int) | Recursive factorial calculation |
| e(double) | Approximates Euler's number |
| ex(double, double) | Calculates e^x series |
