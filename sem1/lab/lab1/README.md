# Lab 1: Introduction to C++ Programming

## Overview

This lab introduces the fundamental concepts of C++ programming, including:
- Basic input/output operations
- Variables and data types
- Arithmetic operators
- Decision-making statements (if-else)
- Program flow control

## Projects in This Folder

| Project | Description |
|---------|------------|
| HelloWorld | Simple "Hello World!" program |
| TestDebug | Basic arithmetic operations |
| TestDebug2 | Three integers input (sum, average, product, smallest, largest) |
| lab1 part b | String output demonstration |

## How to Set Up

1. Open the Visual Studio solution file (`.sln`) in the project folder
2. The project uses C++ and requires no additional dependencies

## How to Run

1. Open the solution in Visual Studio
2. Press `F5` or click Debug > Start Debugging
3. Or compile and run the executable directly from the Debug folder

## Key Details

- All projects follow the basic C++ syntax with `main()` function
