# EIE2111 - Introduction to C++ Programming

## Course Overview

This course introduces fundamental programming concepts using the C++ language. Students learn the basics of C++ syntax, object-oriented programming concepts, and practical application development through hands-on labs and assignments.

## Topics Covered

- Basic C++ syntax and structure
- Variables, data types, and operators
- Input/output operations (cin, cout)
- Decision-making statements (if-else, switch)
- Loops and iteration control
- Functions and modular programming
- Object-oriented programming (classes, objects)

## Labs, Demos, and Homework

The course is organized into two semesters:

### Semester 1
- **Labs 1-6**: Core C++ programming fundamentals including Hello World programs, arithmetic operations, decision-making, loops, and basic data structures

### Semester 2
- **Labs 7-9**: Advanced topics including more complex exercises and algorithms
- **Mini Project**: Comprehensive project applying C++ concepts

### Assignments
- **ass (sem1 & sem2)**: Homework assignments reinforcing lecture material

## Learning Objectives

By the end of this course, students will be able to:
1. Write and debug C++ programs using Visual Studio
2. Understand and apply fundamental programming concepts
3. Implement basic algorithms and data processing
4. Use decision-making and loop structures effectively
5. Apply modular programming with functions

## Software Requirements

- Microsoft Visual Studio (C++ workload)
- Windows OS
